# SISTEMA-BRANQUIA-URBANA
Una solución integral para la gestión de escorrentía pluvial urbana en ciudades de topografía accidentada. A diferencia de los sistemas de alcantarillado convencionales que concentran el caudal en puntos únicos, el Sistema BRANQUIA URBANA® propone una red capilar distribuida de captación de alta frecuencia, con deposición, purificación
